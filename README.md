# JA21-DeepML-Animation-VFX-Language-Suite-1.0.0

Explore language design for particles, fluids, cloth, shaders, materials, and render graphs with JA21 DeepML Animation VFX. The suite combines 10,000 technical records, 1,000 source scripts, an 18-chapter textbook, and offline tools for teaching, retrieval, and implementation research. Modeled outcomes and native execution remain clearly qualified.

The JA21 DeepML Animation VFX Language Suite is an offline collection for studying code-first descriptions of visual-effects pipelines. Its domain includes particles, fields, fluids, cloth, destruction, shaders, materials, lighting, render graphs, caches, and compositing. Educators, technical artists, language designers, and compiler researchers can explore how these concepts are expressed through source examples and evidence contracts.

The suite combines a 10,000-record normalized technical corpus, 1,000 .deepml scripts, and an 18-chapter textbook with appendices. The script pack includes positive, diagnostic, and certification categories. A workbook, instructor guide, curriculum, catalogs, starter project, language reference, grammar assets, compiler contracts, and runtime contracts provide multiple routes through the material. Offline inspection and validation tools support retrieval and dataset analysis.

The audited release adds explicit modeled-evidence qualifications, source hashes, metadata-conflict quarantine, and schema checks. Native GPU execution, numerical validity, and runtime conformance are not established by corpus labels. Parts of the domain grammar remain incomplete, and conceptual Smithson 8S annotations require separately adopted and independently evidenced extensions. The collection is a foundation for teaching and implementation research.

## Corpora and audit records

The supplied corpus layout is preserved under `payload/`. The `audit/` directory and [AUDIT_AND_UPGRADES.md](AUDIT_AND_UPGRADES.md) record source coverage, release changes, and evidence boundaries.

Historical source archives and source manifests remain provenance records. Current publication file hashes are listed in `PUBLICATION_SHA256.json`; licensing changes are recorded in `PUBLICATION_LICENSE_LEDGER.json`.
