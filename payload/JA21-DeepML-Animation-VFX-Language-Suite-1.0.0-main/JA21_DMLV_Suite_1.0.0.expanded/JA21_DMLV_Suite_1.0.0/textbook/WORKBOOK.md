# DeepML VFX Workbook

Use one page per exercise. Record the source script ID, intended visual result, declarations changed, expected compiler stage, actual diagnostic or admission result, source hash, semantic hash, runtime evidence, and replay notes.

## Exercise sequence
1. Rename a module without changing the effect semantics.
2. Change an emitter rate while preserving deterministic streams.
3. Add a force and identify the affected attributes.
4. Introduce and repair an invalid shader interface.
5. Build a three-pass render graph and justify ordering.
6. Create a cache invalidation rule for a changed source asset.
7. Repair a resource hazard without duplicating work.
8. Compare visible overlap with latent coupling under 8S.
9. Document an optimization equivalence proof.
10. Package a capstone with complete replay evidence.
