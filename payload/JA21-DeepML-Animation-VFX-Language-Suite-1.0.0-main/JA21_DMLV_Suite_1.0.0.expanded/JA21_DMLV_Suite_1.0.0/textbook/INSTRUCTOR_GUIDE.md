# DeepML VFX Instructor Guide

## Course intent
Teach code-first animation and VFX as governed language engineering. Every assignment should evaluate visual intent, semantic correctness, deterministic policy compliance, compiler evidence, and replay provenance.

## Assessment model
- 20% language syntax and type discipline
- 20% simulation/render graph design
- 20% diagnostics and repairs
- 20% R12/MCRT and replay evidence
- 20% capstone effect and technical defense

## Recommended capstone evidence
1. Source package and module map.
2. Compiler-stage report.
3. R12 and MCRT records.
4. Runtime trace and cache manifest.
5. Visual output description or studio preview evidence.
6. Determinism and no-network confirmation.
7. Limitations and 8S claim-boundary statement when applicable.
